Find the word you meant to type.

VexDB indexes 25,496 English words as 128-dimension character-trigram vectors. Every keystroke searches all of them through a hand-written HNSW graph in Go and returns the ten nearest — the timer below shows each search in microseconds.

Try a misspelling:

    The ten nearest words appear here as you type, closest first. Not sure where to start? Pick a misspelling above.

    How it's built

    Corpus
    25,496 English words
    Embedding
    char bi/trigrams, 128 dims
    Index
    HNSW graph, Go stdlib only
    Similarity
    cosine, top 10 returned
    About this demo. The trigram embedding is here to make string similarity visible without an ML model — the index underneath doesn't care where vectors come from. Swap in a text-embedding model and the same graph serves semantic search. Read the source on GitHub.
